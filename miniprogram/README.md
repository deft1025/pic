# 小小绘本馆 · 微信小程序

项目根目录执行 `npm run setup:mini`，再用微信开发者工具导入本目录。接口为 `https://pic.xuninfo.top`。账号和统计功能需要先准备五张读者表并启用后端开关；客户端永远不配置AppSecret。

完整说明见 [docs/miniprogram.md](../docs/miniprogram.md)，包含域名、登录、数据表、统计口径与检查方式。

阅读页将语言按钮放在插画上方左侧，全屏入口靠右；翻页、配音、连播与倍速放在图下。隐藏文字与夜间入口已移除，旧偏好不再生效。全屏使用整个可用窗口，保留完整插画比例，支持设备横竖屏；默认收起操作，轻点插画或底部提示呼出，再次轻点插画收起，左上角始终可退出。旁白在独立区域滚动，气泡仍留在原图内。微信状态栏与胶囊属于系统界面。

详情页保留作者和插画师署名，隐藏长篇来源说明、许可类型及复制来源链接按钮；后台来源记录继续保留。

首页、书库和书架列表对当前登录账号完成过的书显示绿色“✓ 已读完”；详情、播放页不额外显示。后端通过 `GET /api/me/completed-books` 从现有 `reader_events` 的complete行读取，无新增表或迁移。客户端返回列表时同步状态，读完事件可先在本机显示并按原队列补发，缓存隔离账号，退出或会话失效清空；游客不记录完成状态。此功能需要后端代码与小程序客户端都更新，接口不可用时保留书目阅读和已有本机账号标记。

读完鼓励动效目前只作试读：微信开发者工具选择本机编译模式“读完鼓励试读·花盆里的一颗豆”，或使用 `pages/reader/index?id=sb-bean-in-a-pot&celebrate=1`。读完全部页面后，使用数据库对白中的实际角色名、插画和指向点显示头像、轻微弹出与鼓掌表情，以及感谢陪读的话。动画有限次播放，保留等宽等高的“再读一次”“返回书架”；横屏全屏面板可滚动。普通入口不启用，不保存为阅读偏好，不新增逐书前端清单或图片素材。此为头像与鼓掌表情的动效，没有改动原画角色的肢体。

书库搜索框使用固定高度、仅左右内边距，输入文字16px、提示文字14px；原生input负责垂直对齐，避免上下内边距挤压文字与光标。浏览器适配渲染已检查，微信真机效果仍需确认。


固定头像集中在 [config/avatars.js](config/avatars.js)：`defaultAvatar` 为游客、未选年龄段与未知年龄段的默认图，`byAge` 下的 `0-2`、`3-4`、`5-6` 为三个年龄段。填入四张正方形图片的HTTPS地址，或包内 `/assets/...` 路径；空项使用默认图，都为空或加载失败则显示书本占位。书架与阅读资料页共用映射，资料页选择年龄段可预览，保存后书架随之更新。仅使用原有年龄字段，不保存独立头像、不提供修改头像按钮、不调用微信头像授权。图片地址随小程序代码发布，替换地址需重新编译发布。

书架个人卡片将头像、昵称和年龄作为主体，修改资料与退出为小号文字操作；修改资料仍可调整称呼与年龄，退出保持原有账号清理逻辑。新版已读接口404/405时兼容旧后端，保留已有状态，网络和服务失败仍提示同步重试。
