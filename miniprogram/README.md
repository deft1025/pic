# 小小绘本馆 · 微信小程序

项目根目录执行 `npm run setup:mini`，再用微信开发者工具导入本目录。接口为 `https://pic.xuninfo.top`。账号和统计功能需要先准备五张读者表并启用后端开关；客户端永远不配置AppSecret。

完整说明见 [docs/miniprogram.md](../docs/miniprogram.md)，包含域名、登录、数据表、统计口径与检查方式。

阅读页将语言按钮放在插画上方左侧，全屏入口靠右；翻页、配音、连播与倍速放在图下。隐藏文字与夜间入口已移除，旧偏好不再生效。全屏使用整个可用窗口，保留完整插画比例，支持设备横竖屏；默认收起操作，轻点插画或底部提示呼出，再次轻点插画收起，退出入口始终可见。短横屏改为左侧插画、右侧旁白及操作，插画占满可用高度，呼出控件不再压缩图片；左右刘海、顶部微信胶囊及底部安全区保留。旋转优先使用onResize事件尺寸，再更新实测布局，不重开书、不改变页码、语言及播放状态。旁白在独立区域滚动，气泡仍留在原图内。微信状态栏与胶囊属于系统界面。

详情页采用主标题、次级英文标题、轻量页数/时长/双语标签、奶油色共读亮点及宽松行距简介；底部为等宽阅读和收藏按钮及小号署名。作者和插画师仅展示名称，移除“AI生成、项目校对”等括号后缀；隐藏长篇来源说明、许可类型及复制来源链接按钮，后台来源记录继续完整保留。网页署名同步精简，详细来源披露仍在来源区域。

书库主题从 `/api/categories` 动态读取，包含“幼儿园适应”（`kindergarten`）；相关新旧绘本统一归入，可同时保留其他标签。主题和分类数据更新后重新进入书库即可读取，不为主题维护前端书单，也不需要专为主题重新编译客户端。新制作的图片与配音仍需上传单书包。

首页、书库和书架列表对当前登录账号完成过的书显示绿色“✓ 已读完”；详情、播放页不额外显示。后端通过 `GET /api/me/completed-books` 从现有 `reader_events` 的complete行读取，无新增表或迁移。客户端返回列表时同步状态，读完事件可先在本机显示并按原队列补发，缓存隔离账号，退出或会话失效清空；游客不记录完成状态。此功能需要后端代码与小程序客户端都更新，接口不可用时保留书目阅读和已有本机账号标记。

所有绘本统一使用读完鼓励，新书自动沿用；普通入口不依赖后端功能字段、逐本开关或预览参数。移除普通与全屏的“读完”按钮；全部页面读过后，最后一页配音自然结束弹出，没有开启配音则在末页停留4秒弹出。开始播放、离开末页、切后台或退出取消静读倒计时；暂停或配音错误不算自然播完。面板渲染后进入原有读完事件队列和列表标记逻辑，重复只记一次。角色区144px、正文18px，有限次点头摇摆，轻点触发上跳、击掌表情和感谢回应；短横屏角色居左，两个操作等宽等高。角色名、插画和指向点来自MySQL的有效对白，不增维护清单；缺少有效角色或头像加载失败时使用书本“故事小伙伴”，仍可击掌、重读和返回书架。动作由现有图片与CSS驱动，没有制作原画肢体逐帧动作。仅需重新编译/发布小程序，不需要改库、更新后端或重打图片配音素材包。旧celebrate=1链接可照常打开。

书库搜索框使用固定高度、仅左右内边距，输入文字16px、提示文字14px；原生input负责垂直对齐，避免上下内边距挤压文字与光标。浏览器适配渲染已检查，微信真机效果仍需确认。


固定头像集中在 [config/avatars.js](config/avatars.js)：`defaultAvatar` 为游客、未选年龄段与未知年龄段的默认图，`byAge` 下的 `0-2`、`3-4`、`5-6` 为三个年龄段。填入四张正方形图片的HTTPS地址，或包内 `/assets/...` 路径；空项使用默认图，都为空或加载失败则显示书本占位。书架与阅读资料页共用映射，资料页选择年龄段可预览，保存后书架随之更新。仅使用原有年龄字段，不保存独立头像、不提供修改头像按钮、不调用微信头像授权。图片地址随小程序代码发布，替换地址需重新编译发布。

书架个人卡片将头像、昵称和年龄作为主体，修改资料与退出为小号文字操作；修改资料仍可调整称呼与年龄，退出保持原有账号清理逻辑。新版已读接口404/405时兼容旧后端，保留已有状态，网络和服务失败仍提示同步重试。

底部“发现 / 书库 / 我的书架”使用 `custom-tab-bar/` 自定义导航，图标在上、16px文字在下；选中项为浅蓝圆角底、深蓝加粗字，底色为奶油白。三页同步真实路由的选中状态，包含程序跳转与从详情返回；页面底部留出导航和安全区，避免遮住分页及列表。图标由WXSS绘制，不需要上传素材。
