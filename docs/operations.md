# 物料制作与交付

在项目根目录运行。MySQL已初始化；日常不运行dbinit、不主动建表或迁移。真实凭据只由现有配置读取，不打印或复制到文档。先查库、检查工作区，保留用户已有变更。

```sh
git status --short
python3 scripts/materials.py list
python3 scripts/materials.py show --book 书ID
go run ./cmd/materials read --book 书ID
```

新增默认至少4本。逐本核实适龄性、完整原文与页序、实际画面、作者插画师及许可；同作品先排重。选择来源和系列见下方“选材来源”。新作品使用新ID，不覆盖旧故事；不自行提交、推送或部署。

新增物料继续归入“幼儿园适应”（`kindergarten`），可兼顾情绪、习惯等标签。选材覆盖温暖的入园、集体生活、交朋友、表达与同伴相处；优先其他主人公和不同画风，丰富列表视觉，不因主题相关就连续选用同一安安角色。来源系列与产品主题分别核实。

新增主题先在Go校验字典和Python物料校验器中定义，再通过 `python3 scripts/materials.py add-category --category 主题ID` 向现有categories表创建一条记录；该命令经过service/repository，只允许已定义主题，重复相同记录安全，已有信息不同则回滚，不覆盖其他主题、不建表、不运行dbinit。前端主题列表读取MySQL；网页主题说明使用API字典描述，不按固定六项数组取值。

Codex将内容在内存中生成，通过标准输入传给 `go run ./cmd/materials save`，结构为 `{book, revision}`。新增revision为空；更新使用刚回读的完整快照revision，不强行覆盖。作者、插画师入库只留创作者名称，自动清理“AI生成”“AI生成原图”“项目校对”等制作后缀；许可与原始来源证据独立保留。已发布书填写一句基于全文的 `reading_value`；制作未完成时可以 `save --metadata-only` 录入正文与预计路径，该阶段不代表交付完成。

先补齐逐本来源证据和原图，再执行指定书制作；缺少来源配置时先重新核验准备，不假定历史文件仍在。StoryBloom制作要求在 `content/sources/storybloom/sources.json` 登记来源和逐页哈希，经 `scripts/storybloom_art.py` 核验后原样保留WebP。书目、图像描述与角色对白只维护MySQL。陌生ID不能靠 `art` 自动获得完整插画。

```sh
python3 scripts/materials.py art --book 书ID
python3 scripts/materials.py audio --book 书ID
ASSET_CHECK_MODE=local python3 scripts/materials.py validate --book 书ID
python3 scripts/materials.py package --book 书ID
python3 scripts/materials.py snapshot-tests
```

配音沿用 `config/audio.json` 中晓晓/Jenny、-20%，每种语言整本成功后事务写回。已匹配全文和参数的音频自动跳过，不因本机副本缺失重配；`prepare`只做配音加打包，不含制图。依赖由Codex核验并准备，不要求用户改JSON或运行importer。

每本独立检查全文、实际图片、双语对白与音频，使用PC和手机阅读流程验收。小程序浏览器适配检查、真实MySQL/本机素材检查、线上资源和微信真机结果分开记录。

单书包为 `web/assets/books/书ID.tar.gz`，包首层为书ID，只含该书封面、正文图片及现有双语音频，不含JSON、来源校对图或系统杂项。核验包内路径、文件数量和字节，音频实际解码。

用户上传到 `/root/www/pic/assets/books/` 后，在该目录逐本执行：

```sh
tar -xzf 书ID.tar.gz
```

不清空旧目录。当前用户要求上传解压后的远程验收由人工完成，不默认执行自动远程检查；用户后续要求Codex验证时使用：

```sh
ASSET_CHECK_MODE=remote python3 scripts/materials.py validate --book 书ID
```

执行自动验收时随后检查公网页面及新书双语资源；上传反馈本身不代表全部验收完成。本批结果和剩余事项写 [验收记录](acceptance.md)。素材更新刷新即可；代码变更由用户自行提交推送、按 `bash deploy.sh` 部署。小程序客户端变更需用户重新编译预览或发布，与后端、素材分开处理。


## 小程序读完鼓励与底栏

读完鼓励是小程序阅读器默认行为，适用于全部现有书与新书，没有逐书启用清单，不依赖API的功能字段。角色和插画从MySQL已有对白读取，缺少有效角色或头像加载失败时显示可互动的“故事小伙伴”。弹窗作为阅读容器外的独立遮罩与flex布局，按窗口和安全区计算原生scroll-view高度，短横屏人物居左；不依赖全屏grid、固定定位变换或超大阴影。返回书架或上一页先停止播放与计时、移除弹窗和全屏层，待渲染完成再跳转；失败可重试。全部页面读过后，末页配音自然结束或静读4秒弹出；面板渲染后执行原有读完记录。

底栏由 `miniprogram/custom-tab-bar/` 维护：图标加16px标签，浅蓝圆角选中态，适配底部安全区；首页、书库、书架同步当前路由，并为栏位预留底部空间。本次动效与底栏只需更新小程序客户端并重新编译/发布，不改库、不重制素材，也无需为这两项更新后端。跨设备已读同步仍需要后端支持既有 `GET /api/me/completed-books` 接口。

## 小程序推荐与收藏

每个登录账号最多20本有效收藏。新增、重新收藏和批量添加在用户行锁保护的事务内计算去重后的总数，超限整批拒绝并提示“最多收藏20本，请先取消部分收藏”；取消收藏及重复请求已有收藏不受阻。规则不自动删减历史收藏，历史超限账号须先取消到可用名额后再添加。

“今天读什么”保留既有分龄、新书与热门推荐规则，所有选择和回补均排除账号自己当前收藏。当日已有缓存也重新核对收藏，只替换命中的卡片，保留其他位置；保存时比较旧批次，遇到并发结果重新校验，不覆盖其他请求的新结果。候选不足时允许少于4本，全部收藏时返回空列表，不为凑数返回已收藏书。刷新或重新进入首页后读取替换结果，游客推荐保持既有规则。

这两项规则由后端处理，现有小程序会显示接口返回的上限提示；更新后端代码并重启即可，无需改表、重编小程序或上传素材。其他客户端改动的发布需求独立判断。

## 时间字段

`books.published_at`在标准入库链中转换为UTC并截断到整秒，不四舍五入。历史小数秒可用 `python3 scripts/materials.py normalize-published-at` 事务整理，该命令只更新有小数秒的发布时间，不改正文、图片或配音，重复执行无改动；不需要修改表结构。

数据库应用连接使用UTC（`time_zone='+00:00'`）。`reader_users.created_at / updated_at`为秒级TIMESTAMP，查询工具采用北京时间会自动显示为UTC加8小时；不要给历史值手工加8小时。`created_at`表示建号，`updated_at`由数据库在资料实际变更时自动更新；重复登录和保存相同资料不会刷新，不作为最近登录时间。

## 小程序全屏阅读

语言、配音播放、连播与倍速在进入全屏前选好，全屏内只保留退出、上一页/下一页和页码，轻点画面呼出或收起翻页。正在播放的配音延续既有状态，退出后再调整；普通阅读保留完整播放器。

手机横屏按全书插画比例和可用窗口比较两种布局，选择完整图片实际显示面积更大的一种：横幅图优先释放整屏宽度，旁白与翻页、退出合并到底部48px字幕带；方图或较窄画幅使用120–152px固定旁白栏，剩余区域全部用于图片，不把剩余宽度继续扩给旁白。长旁白均可滚动。微信胶囊只在实际会与画面或退出按钮重叠时留出位置，保留系统安全区；图片始终aspectFit，不裁剪、不拉伸、不默认放大截去边缘。布局按全书比例及窗口确定，翻页、语言和操作显隐不改变图片尺寸。方图最大尺寸仍受屏幕高度限制；仅手机横屏全屏且方图两侧留空时，使用同页原图的低对比柔化副本填充阅读背景；竖屏和普通阅读不启用，中间原图仍完整、清晰、等比例，气泡只属于原图区域。背景装饰不改变来源图片、数据库或打包素材，不生成虚构故事细节。客户端修改需重新编译预览/发布，浏览器适配检查不代表微信真机。


## 选材来源

先查MySQL排重，再逐本阅读完整原文、核对页序、画面、创作者和许可。书目与交付历史见数据库及 [验收记录](acceptance.md)，不维护重复的静态书单。

- StoryBloom：[公开绘本馆](https://storybloom.valleylmh.vip/library)、[来源仓库](https://github.com/valleylmh/storybloom)。来源系列包括日常、亲子成长、好奇为什么、唐诗入画、谚语故事等；系列、路径与产品主题分别核实，亲子成长曾使用 `/library/sanzijing/` 路径。应用代码MIT不能代替逐本图文许可，未核实权限如实记录pending。
- [Book Dash](https://bookdash.org/)：优先不同原插画师与主人公的开放许可原画，逐本核对具体版本、完整原文、署名和CC BY 4.0依据。同作品不同版本先查库，不用新标题掩盖重复作品。
- African Storybook、StoryWeaver、Let’s Read可逐本考察；平台名称不能代替逐本许可、完整原文与原图核验。

后续幼儿园适应选材优先不同主人公与画风，可放宽至相关情绪、友谊、合作和新环境适应，统一归入kindergarten并保留适当标签；避免训诫、整本无字、拆句或重复图片凑页数。《波西和皮普》仅为温暖动物朋友故事的参考，不代表来源站有该版权系列；此前也未核实独立恐龙系列。来源证据、原图与专用制作配置须逐本准备，已被清理的历史说明不视为现存材料。

## 微信小程序配置

```sh
npm run setup:mini
npm run check:mini
npm run test:mini
npm run test:mini:layout
npm run test:mini:profile
```

在微信开发者工具导入 `miniprogram/`；生成的本机项目配置被Git忽略。接口使用 `https://pic.xuninfo.top`，按现有API与素材地址配置微信合法域名。AppID由配置读取，AppSecret只在后端 `.env`，不写进客户端。

账号功能通过 `MINI_PROGRAM_ENABLED` 开启，依赖用户手动准备的五张读者表：reader_users、reader_sessions、reader_favorites、reader_events、reader_recommendations；日常不运行建表或迁移。游客阅读和偏好保存在本机，不收藏或参与账号统计；登录后收藏、已读与推荐由后端服务提供，不保存阅读进度。

首页、书库、书架通过 `GET /api/me/completed-books` 展示账号已读标记，详情和阅读页不加标记；退出或会话失效清理账号缓存，接口404/405兼容旧后端，网络或服务失败保留同步重试提示。跨设备已读需更新后端与客户端。主题从 `/api/categories` 动态读取，新书与主题数据更新不需专门重编客户端。

固定头像只在 `miniprogram/config/avatars.js` 配置：defaultAvatar及byAge的0-2、3-4、5-6共四张图，使用HTTPS地址或包内路径；空项回退默认，全空或加载失败显示书本占位。资料页和书架共用年龄映射，不申请微信头像或新增头像字段，替换配置地址需重新发布客户端。

阅读页统一使用图内角色气泡和图下旁白；完整对白、图片比例与角色锚点来自数据库，图片失败或无有效对白时保留全文兜底。详情署名仅显示创作者名称，数据库保留来源与许可；网页继续披露来源。阅读器全屏规则及读完鼓励见上文。布局检查区分夹具API、本机实际素材与微信真机，不从浏览器模拟结果推断真机验收。
