# Book Dash 正文与来源快照

本目录仅供离线溯源，不是运行时数据源。原作采用 CC BY 4.0，许可链接：https://creativecommons.org/licenses/by/4.0/ 。原文来自 Book Dash 官方仓库 https://github.com/bookdash/bookdash-books ，对应作品与创作者逐本记录在 `sources.json`。

- `*.md`（本 README 除外）：下载的完整英文故事正文，保留原始分镜顺序；无字页仍留在快照内。
- `meta.yml`：同次下载的官方版本元数据，包含创作者、ISBN、发布日期及逐本权利声明；其署名可能与当前官网新版本不同。
- `sources.json`：实际使用作品的官网链接、正文链接、Git blob SHA、快照 SHA-256、署名、许可与本版无字页串词。

本站书目保存在 `content/books/bd-*.json`。中文为 AI 辅助翻译，插画为本站全新 SVG，并非原作插画；英文的无字页串词已单独标记。不表示原作者、插画师或 Book Dash 为本站背书。适龄选择、校对图、配音和导入进度见 `docs/materials.md`。
